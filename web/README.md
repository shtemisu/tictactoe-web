# TicTacToe — веб-фронтенд

Лёгкий SPA на ванильном JS (без сборки).

## Возможности
- Регистрация / вход (JWT, автообновление access-токена по refresh)
- Игра против ИИ (Минимакс)
- Мультиплеер: создание игры, подключение по UUID, список открытых игр
- Интерактивная доска 3×3 (X — синий, O — оранжевый), статус и определение победителя
- Опрос состояния игры (polling) в мультиплеере, пока ходит соперник
- Профиль (сыграно / победы / винрейт) и таблица лидеров

## Запуск
1. Подними бэкенд: `docker-compose up --build` (API на `http://localhost:8080`).
2. Открой фронтенд любым способом:
   - просто открой `web/index.html` в браузере, **или**
   - подними статику: `cd web && python3 -m http.server 5500`, затем открой `http://localhost:5500`.

По умолчанию фронт обращается к `http://localhost:8080`. Чтобы указать другой адрес,
задай `window.API_BASE` перед подключением `app.js` (или отредактируй константу в `app.js`).

> Бэкенд отдаёт CORS-заголовки (`internal/controller/middleware/cors.go`),
> поэтому фронт работает с любого origin.
